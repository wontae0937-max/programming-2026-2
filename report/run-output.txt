=== 정렬 비교: 병합 · 퀵 · 힙 ===
원소는 (key, tag) 8바이트. key로 정렬하고 tag로 안정성을 본다.

구현 표 (SortAlgorithm이 주장하는 값)
알고리즘       시간복잡도     메모리     안정성
-------------------------------------------------------------------------------------
mergeSort      O(n log n)     O(n)       stable
quickSort      O(n log n)     O(log n)   unstable
heapSort       O(n log n)     O(1)       unstable

읽는 법
  시간   : 같은 기계에서만 견준다. 비교·이동 횟수가 더 믿을 만하다.
  메모리 : 입력 배열 밖에 잡은 바이트. 병합만 temp 배열로 n칸을 더 쓴다.
           퀵은 그 대신 재귀 깊이만큼 스택을 쓴다. 힙은 둘 다 없다.
  안정성 : 표의 주장이 아니라 tag 순서로 실측한 값이다. '-'는 같은 key가
           하나도 없어 판정할 수 없다는 뜻이다 (그때는 어떤 정렬이든 안정해 보인다).
